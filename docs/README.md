# 🎬 Telegram Video Downloader Bot

**Developer**: [@sami3d.t.me](https://t.me/sami3d)

A powerful Telegram bot for downloading videos from Instagram, Facebook, TikTok, YouTube, Twitter, and Kwai with quality selection support.

## 🚀 Quick Start

### 1. Installation
```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### 2. Configuration
Edit `config.py`:
```python
BOT_TOKEN = "your_bot_token"
ADMIN_IDS = [your_telegram_id]
```

### 3. Run
```bash
python main.py
```
